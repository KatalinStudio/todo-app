📝 Todo App

A simple and responsive Todo List application built with **HTML, CSS, and Vanilla JavaScript**.

This project demonstrates DOM manipulation, event handling, state management, and localStorage persistence.

🚀 Features

- ✅ Add new todos
- ✅ Mark todos as completed
- ✅ Delete todos
- ✅ Save todos in localStorage
- ✅ Load saved todos on page refresh
- ✅ Add todos using the Enter key
